# My Study Hub

백엔드 개발을 공부하면서 정리한 자료들을 한 곳에서 볼 수 있도록 만든 문서 허브입니다.

Java, Spring Boot, API, 데이터베이스, Linux 등 다양한 주제의 PDF 학습 자료와 기술 서적 추천, GitHub 레포지토리 링크를 카테고리별로 제공합니다.

공부할 때마다 자료를 찾아 헤매는 번거로움을 줄이고, 필요한 내용을 바로 찾아볼 수 있도록 구성했습니다.

## 기술 스택

`Spring Boot 3.5.7` `Java 17` `Vanilla JavaScript` `GSAP` `Docker` `Nginx` `Netlify`

## 실행

```bash
# Spring Boot
./gradlew bootRun

# Docker
docker build -t my-study-hub .
docker run -p 80:80 my-study-hub
```
